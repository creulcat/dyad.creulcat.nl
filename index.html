Run more than one instance at once.

Dyad /ˈdaɪ.æd/ - a pair; two as one.

Dyad Launcher is a streamlined fork of the Modrinth app, built for running more than one instance at once. Same launcher you know, less clutter, more concurrent play.

Get Dyad Launcher Other versions View on GitHub

What's different

Same Modrinth/Theseus foundation underneath. Refocused on running more than one game at a time.

Familiar foundation

Built on the same Modrinth/Theseus core you already know. Just refocused, not reinvented.

Multi-instance launches

Launch multiple instances at once, under the same or different Microsoft accounts.

Die, ads

Removing the clutter and the advertisements. Pure function.

In progress

Shared resources

Symlink-based sharing of mods, packs, configs, and worlds across instances are pending.

In progress

Keeping the good parts

Discord Rich Presence is pending. Telemetry, account promos, and the news feed are stripped out.
